# Personal Growth Desk / 个人成长工作台

一个面向 Android 的深色极简个人工作台，统一管理每日健身、学习、好句、阅读、英语学习与复盘。

## 产品目标

- 一个 App 完成「计划 → 执行 → 完成 → 复盘 → 连续成长」闭环。
- 离线优先：训练、学习、复盘等个人数据先保存到本地，网络不可用时仍可使用。
- 内容型模块采用「在线获取 + 本地兜底」策略。
- 以 Expo + React Native + TypeScript 实现，后续可使用 EAS Build 打包 Android APK/AAB。

## V1 模块

1. **主界面**：今日进度、连续完成、快速入口、模块状态。
2. **健身记录**：运动项目 / 次数 / 组数 / 总数量自动计算、训练前后激励、完成训练。
3. **学习计划**：新增计划、逐项勾选、完成今日学习、激励语。
4. **每日好句**：每日 5 条，支持朗读与完成状态；在线源优先接入一言，并预留简讯内容适配器。
5. **每日阅读**：每日 2 篇朗读原文，支持 TTS、阅读完成。
6. **每日英语**：30 个单词（单词 / 音标 / 中文 / 发音）、完成后乱序复习；2 篇英语短文，支持朗读/跟读模式。
7. **每日复盘**：自由文本记录当天复盘。
8. **侧边栏**：左上角三横线展开模块导航。

## 体验增强

- 深色高级简约视觉，低饱和强调色。
- 首页统一显示每日完成率与连续打卡 streak。
- 数据按日期隔离，历史记录可扩展为日历与趋势统计。
- TTS 统一朗读层，中文/英文按语言自动切换。
- 后续加入本地通知：好句、阅读、英语、晚间复盘提醒。
- 后续加入导出/备份、桌面小组件、训练/学习统计图。

## 技术路线

- React Native + Expo + TypeScript
- AsyncStorage（V1），后续可平滑迁移 SQLite
- expo-speech：朗读
- expo-notifications：每日提醒（V1.1）
- EAS Build：Android APK/AAB

## 参考方向

产品结构参考公开的 React Native 生产力 / Habit Tracker 项目中的模块化、离线优先、暗色主题、连续打卡与统计思路，但本项目代码与信息架构重新设计。
